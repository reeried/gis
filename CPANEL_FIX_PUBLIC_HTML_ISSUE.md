# Fix: App Still Accessing public_html Instead of nodejs

## The Problem

Your Passenger config shows:
- `PassengerAppRoot "/home/reeg2836/nodejs"` ✅
- But you have a `gissapp` folder with `.htaccess` and `index.php` inside it
- Apache is serving from `public_html` or the `gissapp` folder instead of your Node.js app

## Root Cause

The issue is likely one of these:

1. **Wrong Application Root Path** - Passenger config points to `/home/reeg2836/nodejs` but your files are in `/home/reeg2836/nodejs/gissapp`
2. **Conflicting files in gissapp** - `.htaccess` and `index.php` are causing Apache to serve from there
3. **public_html/gissapp exists** - Apache serves from `public_html` first

## Solution Steps

### Step 1: Verify Where Your Actual Files Are

Check where your `package.json` and `server/index.js` are located:

**Option A: Files are directly in `/home/reeg2836/nodejs/`**
- You should see: `package.json`, `server/`, `dist/`, `uploads/` directly in `nodejs/`
- If this is the case, Passenger config is correct ✅

**Option B: Files are in `/home/reeg2836/nodejs/gissapp/`**
- You should see: `package.json`, `server/`, `dist/`, `uploads/` inside `gissapp/`
- If this is the case, Passenger config is WRONG ❌

### Step 2: Fix Application Root in cPanel

**If your files are in `/home/reeg2836/nodejs/gissapp/`:**

1. Go to **cPanel → Node.js**
2. Find your application (`gissapp`)
3. Click **"Edit"** or settings icon
4. Change **Application root** to: `/home/reeg2836/nodejs/gissapp` (full absolute path)
5. **Save** the changes
6. **Restart** the application

After saving, cPanel will automatically update the Passenger config to:
```
PassengerAppRoot "/home/reeg2836/nodejs/gissapp"
```

### Step 3: Remove Conflicting Files

If there's a `gissapp` folder with `.htaccess` and `index.php` that shouldn't be there:

1. **Via cPanel File Manager:**
   - Navigate to `/home/reeg2836/nodejs/gissapp/`
   - **Delete or rename:**
     - `.htaccess` (if it's not needed for Node.js)
     - `index.php` (this is a PHP file, not needed for Node.js)
     - `.well-known`, `cgi-bin`, `home` folders (if not needed)

2. **Why remove them:**
   - `.htaccess` can override Passenger settings
   - `index.php` makes Apache think it's a PHP app
   - These files can cause Apache to serve from this folder instead of proxying to Node.js

### Step 4: Check public_html

1. **Via cPanel File Manager:**
   - Navigate to `/home/reeg2836/public_html/`
   - Check if `gissapp` folder exists there
   - If yes, **delete or rename it** (e.g., `gissapp_backup`)

2. **Why this matters:**
   - Apache serves `public_html/` by default
   - If `public_html/gissapp` exists, Apache will serve from there first
   - Your Node.js app never gets the request

### Step 5: Verify Passenger Config Location

The `.htaccess` file with Passenger config should be in the **same directory** as your `package.json`:

- If files are in `/home/reeg2836/nodejs/` → `.htaccess` should be there
- If files are in `/home/reeg2836/nodejs/gissapp/` → `.htaccess` should be there

**Check:** The `.htaccess` file you showed should be in the same folder as `package.json` and `server/index.js`.
